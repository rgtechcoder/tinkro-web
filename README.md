# 🚀 Tinkro Web - Educational Robotics Platform

## 📋 Project Overview
Modern web platform for Tinkro's educational robotics kits and STEM learning resources. Built with React.js, featuring advanced admin panel, dynamic blog management, and user-friendly interface.

## ✨ Key Features
- 🎛️ **Advanced Admin Panel** - Complete content management system
- 📝 **Dynamic Blog System** - CRUD operations with Base64 image support  
- 🎠 **Auto-Sliding Carousel** - Engaging blog presentation
- 🖼️ **Direct Image Upload** - No external hosting needed
- 📱 **Responsive Design** - Mobile-friendly interface
- ⚡ **Fast Performance** - Optimized loading and interactions

## 🔧 Tech Stack
- **Frontend:** React.js, Vite, TailwindCSS
- **Animations:** Framer Motion
- **Storage:** localStorage (client-side)
- **Routing:** React Router DOM
- **Icons:** Lucide React

## 🚀 Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production  
npm run build
```
